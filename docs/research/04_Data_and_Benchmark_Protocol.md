# 数据与基准协议

## 实例层级

1. **微型生成实例（n=6–12）**：穷举所有 tour，提供真正最优值，用于证明零错误删除。
2. **pr299**：ElimTSP 自带 TSPLIB 与稀疏边集，作为首个端到端回归。
3. **pcb3038**：首个中型正确性与吞吐实验。
4. **rl5915、d15112**：通过门禁后扩展，避免首期磁盘和调试成本失控。
5. **ML4CO 记录**：仅在转换、重新认证后使用，不继承原文件标签。

## 规范化与清单

每个实例清单记录：源 URI/相对路径、原始 SHA-256、规范化 SHA-256、维度、距离类型、坐标是否整数、边集哈希、上界、上界来源和证书状态。TSPLIB 节点号转成内部 0-based；输出 Concorde 边文件仍为 0-based。

ML4CO 浮点坐标转换使用显式比例 `10^6` 和整数 `EUC_2D`。转换后的实例视为新实例，运行 exact solver 或提供可独立检查的 tour/下界证书后才能写 `certified_optimum`。

## 正确性指标

- 删除边中出现在任一已知最优 tour 的数量（必须为 0）；
- CPU verifier 拒绝率及原因；
- CPU/GPU 最终边集与证明哈希；
- 图连通性、每点度数、受保护 tour 完整性；
- 重放证明后的边集逐字节一致性。

已知一个最优 tour 只能证明“没有删掉该 tour”，不能证明不存在另一最优 tour 被破坏。微型实例用全枚举补足；大实例依赖理论规则与独立证明重放。

## 性能指标

记录硬件、驱动、CUDA、编译器、提交号、参数、GPU 空闲显存和热状态。报告总耗时、每阶段耗时、峰值显存、edges/s、候选接受率、最终 `m/n`。CPU 对照固定线程数和 NUMA；GPU 预热一次后统计至少 5 次。

## 实验产物

每次运行创建 `artifacts/<run-id>/`：`run-manifest-v1`、stdout/stderr、proof、输入清单、最终边集和 metrics。默认保留最近 3 个大实例快照；磁盘可用空间低于 8 GiB 时拒绝新运行。
